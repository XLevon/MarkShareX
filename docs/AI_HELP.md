# MarkShareX AI 助手使用帮助

## 快速导航

直接说去向，秒级跳转（不经过 AI）：

| 说法 | 效果 |
|------|------|
| `去首页` / `回主页` | 跳转到首页 |
| `去知识库` | 跳转到知识库列表 |
| `去分类` | 跳转到分类页面 |
| `去标签` | 跳转到标签列表 |
| `去搜索` | 跳转到搜索页面 |
| `去留言板` | 跳转到留言板 |

## 站内搜索

```
搜索 Rust 相关文章
找 Docker 部署教程
```

AI 会调用搜索接口，返回文章标题 + 可点击链接。

搜索只匹配标题和摘要（正文需点击进入后加载），所以搜索结果以标题匹配为准。

## 页面跳转

搜索到结果后，可以继续指挥 AI 跳转：

```
打开第一篇
跳转到那篇 Rust 文章
```

AI 会选择匹配的结果并跳转到对应页面。

## 数据查询

```
有哪些分类？
列出所有标签
```

AI 会调用 API 查询站内数据并以表格或列表形式展示。

## 斜杠命令

| 命令 | 效果 |
|------|------|
| `/new` | 创建新对话 |

## 小技巧

- **一次问一件事**：指令越具体，结果越准确
- **搜索优先**：不确定站内有没有相关内容时，先搜索
- **链接可点击**：AI 返回的文章链接可以直接点击跳转
