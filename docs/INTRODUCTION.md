# MarkShareX — 轻量自托管 Markdown 博客系统

> **纯 AI 构建 · AI 托管 · Rust 驱动 · 轻量高效 · 人机协作 · Markdown 博客**

> Rust + Vue 3 + SQLite | 前后台分离 | 全文搜索 | SSR | 多人协同 | 编译嵌入单二进制

---

## 为什么是 MarkShareX

用 **AI Vibe Coding** 的方式写代码，用 **Rust** 的安全高效跑服务，用 **Markdown** 的纯粹方式写文章，用最开放的架构迎接 AI 时代，利用 AI 来学习 AI、驾驭 AI。

MarkShareX 不是一个传统意义的手写项目——它的绝大多数代码由 AI Agent（ Hermes Agent / Deepseek）在与开发者的人机对话中迭代生成。这本身就是一场实验：**AI 到底能不能构建生产级应用？** 答案是肯定的。

## 核心理念

市面上的博客方案要么太重（WordPress），要么太轻（静态站点生成器），要么太商业化（Medium/知乎）。MarkShareX 定位于**中间地带**：

| 方案 | 优势 | 劣势 |
|------|------|------|
| WordPress | 生态丰富 | 重量级，PHP，安全漏洞多 |
| Hexo/Hugo | 纯静态，速度快 | 无管理后台，无在线编辑 |
| Ghost | 现代 UI | Node.js 依赖重，资源消耗大 |
| Notion | 写作体验好 | 数据不在自己手里，SEO 差 |
| **MarkShareX** | **自托管 + 管理后台 + 全文搜索 + 单二进制** | 新兴项目，生态待建设 |

**核心差异化**：一个 `marksharex` 二进制文件搞定一切，无需 Nginx/PHP/Node.js 运行时依赖。更重要的是——**这个项目本身就是用 AI 写的**，从架构设计到代码实现，人机协作贯穿始终。

## 功能矩阵

### 📝 内容创作
- **Vditor 编辑器**：IR 即时渲染模式，支持 Markdown 快捷输入、工具栏、全屏写作、暗色模式
- **知识管理**：文章草稿/发布、二级分类归属、标签关联、封面图
- **本地资源库**：图片/文件上传、MD5 去重、批量操作、未引用文件检测清理
- **网络资源管理**：外链图片入库，URL 变更后全站引用自动同步，杜绝图片失效
- **批量导入导出**：Markdown + 图片 ZIP 包，兼容 CSDN 博客格式，YAML Front Matter 解析

### 🔍 阅读体验
- **全文搜索**：Tantivy 引擎 + CJK 中文分词，统一搜索文章/标签/作者
- **SSR 服务端渲染**：Tera 模板引擎，SEO 友好，OG 标签完整
- **多维度浏览**：按分类（树形结构）、标签、作者筛选
- **评论系统**：匿名/登录评论、嵌套回复、评论审核
- **互动功能**：文章点赞、浏览统计、阅读日志、前后篇导航
- **代码增强**：自动代码复制按钮，登录内容保护

### 🛠️ 管理后台
- **仪表盘**：文章/阅读/点赞/评论统计卡片，每日增量角标，阅读趋势图
- **知识库管理**：文章/分类/标签 CRUD，状态筛选，角色权限
- **资源库**：拖拽上传，网格/列表视图，未引用检查，批量删除
- **用户管理**：RBAC 四角色（admin/sub_admin/author/visitor），登录日志
- **作者申请**：访客提交 → 管理员审核，附备注
- **数据分析**：文章排行、阅读日志、点赞记录、浏览趋势
- **明暗主题**：CSS 变量驱动，编辑器跟随切换
- **系统设置**：站点 Logo/标题/副标题、友链、评论审核开关
- **版本说明**：更新日志管理
- **API Key**：支持 X-API-Key 认证，AI 托管友好

## 技术架构

```
┌─────────────────────────────────────────────┐
│                   Nginx                      │
│            (可选，生产推荐)                    │
├─────────────────────────────────────────────┤
│                  Axum 0.7                    │
│         ┌──────────────┬──────────────────┐ │
│         │  SSR 路由     │  API 路由 (/api) │ │
│         │  (Tera 模板)  │  (RESTful)       │ │
│         └──────┬───────┴────────┬─────────┘ │
│         ┌──────┴───────┬────────┴─────────┐ │
│         │  comrak+ammo  │  SeaORM          │ │
│         │  (Markdown)   │  (ORM)           │ │
│         └──────────────┴────────┬─────────┘ │
│                          ┌──────┴──────┐     │
│                          │   SQLite    │     │
│                          └─────────────┘     │
│                          ┌─────────────┐     │
│                          │  Tantivy    │     │
│                          │  (全文搜索)  │     │
│                          └─────────────┘     │
├─────────────────────────────────────────────┤
│              静态文件服务                     │
│         Vue 3 SPA (前端管理后台)              │
│         SSR 页面 (前台浏览)                   │
└─────────────────────────────────────────────┘
```

### 技术选型理由

| 组件 | 选择 | 理由 |
|------|------|------|
| 语言 | **Rust** | 零成本抽象，内存安全，编译为单二进制 |
| Web 框架 | **Axum 0.7** | 类型安全，tower 生态，性能顶级 |
| ORM | **SeaORM** | 异步优先，迁移管理，类型安全查询 |
| 数据库 | **SQLite** | 零配置，单文件，备份简单 |
| 搜索引擎 | **Tantivy** | Rust 原生，CJK 中文分词，无需外部服务 |
| 前端框架 | **Vue 3 + TS** | 生态成熟，响应式系统，组合式 API |
| UI 组件 | **Naive UI** | 树摇优化，暗色模式，TypeScript 原生 |
| 编辑器 | **Vditor** | 即时渲染，所见即所得，插件丰富 |
| 样式 | **Tailwind v4** | 原子化 CSS，暗色模式，JIT 编译 |
| Markdown | **comrak** | Rust 原生，GFM 兼容，安全渲染 |

## 角色权限体系

```
admin ────── 完全权限 ──────── 用户管理、系统设置、AI 调度
  │
sub_admin ── 管理权限 ──────── 内容管理、审核申请
  │
author ───── 创作权限 ──────── 自己的文章/分类/评论
  │
visitor ──── 只读权限 ──────── 浏览、评论、申请作者
```

## 部署方式

### Docker（推荐体验）
```bash
git clone https://github.com/XLevon/MarkShareX.git
cd MarkShareX
docker compose up -d
```

### 单二进制（推荐生产）
```bash
cargo build --release
./target/release/marksharex
```

一个二进制文件包含：HTTP 服务 + SSR + API + 静态文件 + SQLite + 全文搜索，无需外部运行时。
